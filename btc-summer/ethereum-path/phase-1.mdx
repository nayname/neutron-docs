## Vault Behavior

### Base Vaults

The campaign's primary vaults seek to bootstrap liquidity and lending supply for key assets across the ecosystem. They can be sorted into 3 primary categories:

- **1. BTC LST Vaults with maxBTC**
    - Separate vault for each denomination: **eBTC, LBTC, uniBTC, solvBTC**.
    - Each vault pairs the deposit asset with **maxBTC** in liquidity pools for **BTC yield** and **trading fees**.
    - A portion of deposits is lent out to generate **lending yields**.
- **2. wBTC Vaults**
    - Accepts **wBTC deposits**.
    - Pairs wBTC in an LP with one of the following per vault: **eBTC, LBTC, uniBTC, solvBTC.**
    - Remaining wBTC is lent out to earn **stable, BTC-denominated yield**.
- **3. USDC Liquidity Vaults**
    - Accepts USDC **deposits**.
    - Bridges USDC to Neutron via CCTP.
    - Single sided deposits USDC to the USDC - maxBTC Supervault.

### Bespoke Vaults

The campaign also includes specific vaults with custom behaviors that perform specific roles such as introducing MaxBTC to the ecosystem.

- **4. MaxBTC Deposit Vault (KYC Required)**
    
    <Note>
    Contrary to other vaults, the MaxBTC Deposit Vault is not incentivized as part of the campaign, and not subject to withdrawal penalties. Depositors are encouraged to withdraw maxBTC and use it across the DeFi ecosystem to generate additional rewards.
    </Note>
    
    - Accepts wBTC deposits.
        - For deposits < $100k, requires SumSub KYC via the application.
        - For larger deposits, whiteglove service is available upon request via @structured_EarlyAccess on Telegram
    - Mints and holds maxBTC.
- **5. MaxBTC Liquidity Vault (KYC Required)**
    - Accepts wBTC deposits.
        - For deposits < $100k, requires SumSub KYC via the application.
        - For larger deposits, whiteglove service is available upon request via @structured_EarlyAccess on Telegram
    - Mints MaxBTC.
    - Provides MaxBTC liquidity as a single sided deposit to the MaxBTC - wBTC pair.

### Fees

Phase 1 vaults charge a 0.025% deposit and withdrawal fee in order to cover the cost of bridging assets to Neutron.
