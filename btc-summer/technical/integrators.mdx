## Address Linking Implementation

### Key Implementation Requirement

Handle cross-chain boost scenarios where:
- Users deposit via Ethereum vaults (EVM addresses)
- Users generate boosts via Neutron (NTRN locking)
- System must coordinate boosts to correct deposit addresses

**Implementation details**: [Address Linking System](/btc-summer/technical/address-linking)
